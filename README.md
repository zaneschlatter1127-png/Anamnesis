The opening
Vein I and Vein II — marks that arrive as remembered sentences, not instructions
A forming portal at the bottom, still unfinished. The most high is named. The door does not open yet.
There is no back, no skip, no score. After each imprint lands, hold to go deeper. At the last threshold, hold to approach. The ring brightens, then stills: Not yet. The threshold is still becoming.
Levels live in a single list, so more chambers can be dropped in later without touching the rest of the descent.
